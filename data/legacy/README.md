# Historical comparison

Archived comparison rows from the 8 October 2026 research revision, read by `code/ph_emp3.py` alongside the revised-panel estimates.

- `historical_quadrature_nll.csv`: seven rows labelled `old_panel_old_M1_params` in `data/raw/emp/quadrature_nll.csv`.
- `historical_quadrature_fits.csv`: two rows labelled `oldpanel_Q160` and `oldpanel_Q24` in `data/raw/emp/quadrature_fits.csv`.
- `provenance.json`: archive and source-file hashes, exact row selections and row counts.

Numeric strings and empty fields are preserved from the source CSVs. These files contain the saved earlier-panel results; the revised-panel estimation is run by `code/ph_emp3.py`.
