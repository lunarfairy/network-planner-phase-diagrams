# Figure and input map

All plots are generated by `analysis/make_figures.py`; their processed inputs are generated by `analysis/build_tables.py`. `analysis/make_source_data.py` exports the corresponding tables to a workbook.

|---|---|---|

The [SI content map](SI_CONTENT_MAP.md) lists all old-to-new numbers and archived-data locations. The source-data workbook retains 25 sheets: README plus 24 data sheets.
